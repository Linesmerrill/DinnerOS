# Working on DinnerOS

## Don't stop on a question

Never end a turn waiting on a question while there is queued work you can do.
Ask the question, state the default you'll use, and keep working on the next
item. Stop only when truly blocked: it needs credentials, money, an action on a
real device, or an irreversible decision.

End every turn with one line:

- `Continuing with <X>`, or
- `BLOCKED: <exact thing needed>`
